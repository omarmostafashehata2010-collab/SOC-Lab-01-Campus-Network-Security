# SOC Lab 01 - Secure Campus Network

## 🎯 الهدف
بناء شبكة آمنة لشركة وعزل الأقسام عن بعض بـ VLANs و ACLs

## 🔧 اللي اتعمل
- 3 VLANs (IT: 192.168.10.0 / HR: 192.168.20.0 / Guest: 192.168.30.0)
- DHCP & DNS Server
- Access Control List لمنع Guest من الوصول لـ IT
- Switch Hardening

## 🛠️ الأدوات
Cisco Packet Tracer, VLAN, ACL, DHCP, DNS
